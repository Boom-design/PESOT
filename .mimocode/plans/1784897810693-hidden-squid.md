# Plan: Rename Office-based tab back to In-house on LRA page

## Context
The user clarified that "Office-based" is a concept for **job vacancy staff only**, not LRA staff. The LRA page (manage job activities) should use the tab label **"In-house"**. Both views currently show "Office-based" as the tab name.

Additionally, `office_based` pending jobs need to be visible to LRA for approval — currently they fall into a gap (not in Office-based tab, not in Job Vacancies tab which only shows approved).

## Changes

### 1. `resources/views/staff/inhouse/index.blade.php`
- **Line 10**: Rename tab from `Office-based` → `In-house`
- **Line 28**: Rename page title from `Office-based Interview Schedules` → `In-house Interview Schedules`
- **Line 31**: Rename description from `employer office-based interview requests` → `employer in-house interview requests`

### 2. `resources/views/staff/jobs/index.blade.php`
- **Line 10**: Rename tab from `Office-based` → `In-house` (same tab navigation shared across pages)

### 3. `app/Http/Controllers/StaffWebController.php` — `inhouseSchedules()` (line 866)
- Change `->where('schedule_type', 'inhouse')` to `->whereIn('schedule_type', ['inhouse', 'office_based'])` so pending `office_based` jobs also appear on the LRA page for approval
- The scheduled_count calculation (line 880) should also be updated to match

## Verification

- Pending inhouse jobs appear on LRA page
