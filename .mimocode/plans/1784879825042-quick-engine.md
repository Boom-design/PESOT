# Fix Migration Error: Table Already Exists

## Problem
`php artisan migrate` fails with:
```
SQLSTATE[42S01]: Base table or view already exists: 1050 Table 'job_fair_employment_requests' already exists
```

The table `job_fair_employment_requests` already exists in the database, but Laravel's `migrations` table doesn't have a record of the migration `2026_07_09_114230_create_job_fair_employment_requests_table` being run.

## Root Cause
The table was likely created manually, by another process, or the migration ran but the `migrations` table entry was lost/corrupted.

## Solution: Mark migration as run (no destructive changes)

### Step 1: Verify table structure
Check the existing table has the correct columns and constraints:
```sql
DESCRIBE job_fair_employment_requests;
SHOW CREATE TABLE job_fair_employment_requests;
```
Expected: `id`, `job_fair_id`, `employer_id`, `job_id`, `created_at`, `updated_at` + UNIQUE on (`job_fair_id`, `job_id`)

### Step 2: Register the migration in Laravel's migrations table
```sql
INSERT INTO migrations (migration, batch)
VALUES ('2026_07_09_114230_create_job_fair_employment_requests_table', (SELECT COALESCE(MAX(batch), 0) + 1 FROM migrations));
```

### Step 3: Run remaining pending migrations
```bash
php artisan migrate
```

## Verification
1. Run `php artisan migrate` — should succeed without errors
